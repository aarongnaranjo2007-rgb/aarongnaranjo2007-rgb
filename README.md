* **Atención al detalle en UI/UX:** Manejo de estados de carga (*skeletons/spinners*), manejo de errores de red y diseño *mobile-first*.
* **Trabajo colaborativo:** Uso de Git con *commits* semánticos, ramas por funcionalidad (*feature branches*) y documentación clara.
